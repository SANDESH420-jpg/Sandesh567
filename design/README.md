# Design & Architecture Artifacts

This directory contains the structural and behavioral design specifications for the **Online Examination Process System**.

## Contents

- [uml_diagrams.md](./uml_diagrams.md): Contains 4 full Mermaid UML diagrams:
  1. **Use Case Diagram** (Actors & System Capabilities)
  2. **Class Diagram** (Data Entities, Relationships, Methods)
  3. **Sequence Diagram** (Exam Taking & Real-time Auto-save Flow)
  4. **State / Activity Diagram** (Complete Lifecycle of an Examination)

## Visual Rendering

All diagrams in `uml_diagrams.md` are formatted using GitHub-native [Mermaid.js](https://mermaid.js.org/) code blocks (` ```mermaid `).

GitHub will render these diagrams visually directly inside your browser when browsing the repository. You can also render or export them into SVG/PNG images using the [Mermaid Live Editor](https://mermaid.live) or `mmdc` (Mermaid CLI).
