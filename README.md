# Online Examination System

[![Repository Structure](https://img.shields.io/badge/Structure-Software%20Engineering%20Process-blue.svg)](./online-examination-process/README.md)
[![Status](https://img.shields.io/badge/Status-Completed-brightgreen.svg)](./online-examination-process/reports/final_report.md)

Welcome to the **Online Examination System** repository. This project contains the end-to-end software engineering documentation, architectural design, quality assurance matrix, and management reports for a web-based examination platform.

---

## 📂 Repository Structure

```
online-examination-process/
├── README.md                          ← Team roles, structure, commit plan
├── requirements/
│   ├── README.md                      ← Requirements overview
│   └── requirements_document.md       ← Complete SRS (Functional & Non-Functional)
├── design/
│   ├── README.md                      ← Architecture & rendering guide
│   └── uml_diagrams.md                ← 4 Mermaid diagrams (Use Case, Class, Sequence, State/Activity)
├── testing/
│   ├── README.md                      ← Testing strategy & pass rates
│   └── test_cases_and_matrix.xlsx     ← Excel Test Cases & Traceability Matrix
└── reports/
    ├── README.md                      ← Project reports overview
    ├── gantt_chart.xlsx               ← WBS Schedule & Gantt Chart workbook
    ├── product_backlog_and_sprint_plan.md ← Product Backlog & 4-Sprint execution plan
    └── final_report.md                ← Final project completion summary
```

## 💻 GitHub Remote Instructions

To push this complete structure to your GitHub repository `https://github.com/SANDESH420-jpg/Online-Examination-System`:

```bash

git init
git branch -M main

# 2. Add remote repository URL
git remote add origin https://github.com/SANDESH420-jpg/Online-Examination-System.git

# 3. Add all files and commit
git add .
git commit -m "docs: complete online-examination-process repository structure with SRS, UML, test cases, and sprint reports"

# 4. Push to GitHub main branch
git push -u origin main
```
