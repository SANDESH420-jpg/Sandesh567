# Requirements Engineering Artifacts

This directory contains the formal requirements specification and analysis for the **Online Examination Process System**.

## Contents

- [requirements_document.md](file:///Users/sandeshchaudhary/Desktop/project%20structure%20github/online-examination-process/requirements/requirements_document.md): Complete Software Requirements Specification (SRS) detailing functional requirements, non-functional requirements, system boundaries, and user roles.

## Requirements Scope & Baseline

The requirements baseline covers:
1. **User Authentication & Role-Based Access Control (RBAC)**
2. **Question Bank & Assessment Authoring**
3. **Exam Scheduling & Candidate Registration**
4. **Real-time Assessment Engine & Auto-Save**
5. **Anti-Cheating & AI Proctoring Protocol**
6. **Automated Evaluation, Grading & Analytics**
