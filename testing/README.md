# Quality Assurance & Testing Artifacts

This directory contains the testing strategy, test cases, and requirements traceability matrix for the **Online Examination Process System**.

## Contents

- [test_cases_and_matrix.xlsx](./test_cases_and_matrix.xlsx): Comprehensive Excel workbook containing:
  1. **Requirements Traceability Matrix (RTM)**: Mapping system requirements (FR/NFR) to specific test cases.
  2. **Test Cases Sheet**: Detailed test cases covering unit, integration, security, proctoring, and performance testing.
